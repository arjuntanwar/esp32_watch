# esp32_watch is a free and open-source distributed version control system used to track changes in files, especially source code during software development.

It helps developers:

save project history
manage code versions
collaborate with teams
restore old files
track modifications
work on different features using branches

Git works locally on your computer and can also connect to online platforms like:

GitHub
GitLab
Bitbucket
Main Features
Fast and lightweight
Offline support
Branching and merging
Secure version tracking
Open source
Supports collaboration
Common Uses
Software development
ESP32/Arduino project backup
Website development
Team coding projects
Open-source projects
Example

If you change your ESP32 code and something breaks, Git lets you return to the previous working version easily.
